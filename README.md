# Mastercard Web Component with JavaScript

A clean and modern Mastercard-inspired card UI built with plain HTML, CSS, and JavaScript. This project demonstrates a responsive banking card component with a balance section, masked card number, expiry date toggle, and action buttons for transfer and receive flows.

It is designed for developers and designers looking for a simple, reusable snippet for a Mastercard web component, fintech card UI, or financial dashboard card concept.

## What this code does

This project renders a single-page web component styled like a Mastercard payment card. It includes:

- A premium banking card layout inspired by Mastercard branding
- A balance panel with a realistic amount display
- A masked card number with interactive reveal behavior
- Expiry date toggle interaction for demo purposes
- Responsive layout for desktop and mobile screens
- Buttons for transfer and receive actions
- A lightweight JavaScript interaction layer without external frameworks

## Files

- `index.html` – markup for the card layout and interactive elements
- `styles.css` – modern visual styling, color palette, spacing, and responsive design

## Features

### Mastercard-inspired design
The visual style uses deep blue, orange accent tones, and a card-like structure that resembles a modern banking interface.

### Interactive card behavior
The JavaScript adds simple click-to-toggle interactions:

- Balance can be hidden or revealed
- Card number can be toggled between masked and visible values
- Expiry date can be revealed as a demo effect

### Responsive UI
The layout adapts to smaller screens while keeping the card readable and visually balanced.

### Lightweight implementation
Built using native web technologies, which makes it easy to reuse and customize without a framework.

## Tech stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome icons

## How to run

1. Clone the repository.
2. Open `index.html` in your browser.
3. The card demo will render immediately.

You can also serve it locally using a basic HTTP server if preferred:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in the browser.
